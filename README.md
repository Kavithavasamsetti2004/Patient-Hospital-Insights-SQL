# Patient & Hospital Insights Using SQL

## Project Overview
Analyzed patient demographics, hospital appointments, doctor consultations, and consultation revenue using MySQL.

## Tools & Technologies
- MySQL
- SQL

## Dataset
- Patients Table — 150 records
- Appointments Table — 50 records
- Both tables connected through `patient_id`

## SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- INNER JOIN
- CASE statements
- Subqueries and CTEs
- Window functions for cumulative revenue analysis

## Analysis Performed
- Patient demographics by age, gender, and city
- Department-wise doctor counts
- Top cities by registered patients
- Doctor-wise consultation activity
- Monthly appointment trends
- Department-wise consultation revenue
- Monthly and cumulative revenue analysis

## Key Findings
- Identified 42 unique doctors.
- Cardiology had the highest doctor count.
- July recorded the highest number of appointments.
- Analyzed consultation fees and revenue distribution across departments.
